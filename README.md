# Rock, Paper, Scissors

A simple Rock, Paper, Scissors game made with Python.

## How to Play

1. Run the Python file.
2. Enter ROCK, PAPER, or SCISSORS.
3. The computer randomly chooses one.
4. The winner is announced.
5. Choose whether to play again.

## Requirements

- Python 3

## How to Run

```bash
python main.py
```
